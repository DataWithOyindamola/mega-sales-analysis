Mega Retail Stores Sales Analysis

Project Overview

This project analyses 36 retail sales transactions across 15 stores and 5 regions in Nigeria using Microsoft Excel.

Tools Used

Microsoft Excel

Pivot Tables

Lookup and Text Functions

Data Cleaning and Standardisation

Key Findings

Highest-performing region: North, with total sales of ₦28,470.

Strongest quarter: Q4, with total sales of ₦20,567.50.

Product insight: Grocery — Beans generated ₦4,650 across 4 transactions.
